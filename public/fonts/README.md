# Font sources

Self-hosted WOFF2 files downloaded from the Fontshare CSS API on 24 October 2026.

- Gambarino Regular: https://www.fontshare.com/fonts/gambarino
- General Sans Regular and Medium: https://www.fontshare.com/fonts/general-sans
- Publisher: Indian Type Foundry / Fontshare. Consult the original font pages for licensing terms.

Only the three WOFF2 files used by the website are included. The CSS uses font-display: swap; no runtime request to Fontshare is needed.

Modern revision: General Sans Semibold added from the same Fontshare family. The current UI uses General Sans only.
